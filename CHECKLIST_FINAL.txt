⚠️ HAL PENTING YANG HARUS DIINGAT:
═══════════════════════════════════════════════════════════════════════════════

1. DATA HILANG JIKA REFRESH
   → Cara admin input data, jangan ditutup/refresh
   → Gunakan catatan untuk backup

2. FILE BESAR BISA SLOW
   → SKL PDF sebaiknya < 10MB
   → Compress jika terlalu besar

3. BROWSER HARUS MODERN
   → Chrome, Firefox, Edge (semua bagus)
   → Jangan Internet Explorer (sudah deprecated)

4. DATA HANYA SAAT SESSION
   → Jika mau permanent, perlu database
   → Untuk sekarang ini, aplikasi sudah cukup

5. SECURITY BASIC SAJA
   → Password bukan enkripsi tingkat tinggi
   → Untuk sekolah level ini, sudah cukup
