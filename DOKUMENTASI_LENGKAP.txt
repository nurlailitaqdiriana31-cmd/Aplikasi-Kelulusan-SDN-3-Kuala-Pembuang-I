🌐 CARA ONLINE-KAN KE GITHUB PAGES (RECOMMENDED)
─────────────────────────────────────────────────────────────────────────────

STEP 1: Siapkan Akun GitHub (Gratis)
├─ Buka: https://github.com
├─ Klik: Sign up
├─ Isi: Email, Password, Username
└─ Verifikasi email Anda

STEP 2: Buat Repository Baru
├─ Login ke GitHub
├─ Klik: "+" (sudut kanan atas)
├─ Pilih: "New repository"
├─ Isi:
│  ├─ Repository name: sistem-kelulusan-siswa
│  ├─ Public: ✓ (pilih ini)
│  └─ Add README: ✓ (pilih ini)
└─ Klik: "Create repository"

STEP 3: Upload File HTML
├─ Di halaman repository, klik: "Add file" → "Upload files"
├─ Drag & drop atau click untuk upload: sistem_kelulusan_siswa.html
├─ (Opsional) Upload juga: index.html
├─ Tulis pesan: "Tambah aplikasi sistem kelulusan siswa"
└─ Klik: "Commit changes"

STEP 4: Aktifkan GitHub Pages
├─ Klik: "Settings" (ikon gear di kanan atas)
├─ Di sidebar, cari: "Pages"
├─ Di bagian "Source":
│  ├─ Branch: main
│  └─ Folder: / (root)
├─ Klik: "Save"
└─ Tunggu 1-2 menit (ada progress bar)

STEP 5: Dapatkan URL
├─ Refresh halaman Settings → Pages
├─ Akan muncul: "Your site is published at:"
├─ Klik link tersebut
└─ SELESAI! Aplikasi Anda sudah ONLINE!

📌 URL aplikasi akan seperti:
   https://[username].github.io/sistem-kelulusan-siswa/sistem_kelulusan_siswa.html

   Atau lebih pendek jika upload index.html:
   https://[username].github.io/sistem-kelulusan-siswa/

🚨 TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────

PROBLEM 1: Buka file lokal
SOLUSI: Browser → File → Open → Pilih sistem_kelulusan_siswa.html

PROBLEM 2: Data hilang setelah refresh?
SOLUSI: Normal! Data sementara. Gunakan catatan atau screenshot.
        Untuk permanent, perlu tambah database (next step).

PROBLEM 3: GitHub URL tidak bekerja?
SOLUSI:
   a) Tunggu 5-10 menit (GitHub Pages build)
   b) Ctrl+F5 (hard refresh)
   c) Cek Settings → Pages → Source
   d) Pastikan repository PUBLIC

PROBLEM 4: File PDF tidak bisa diupload?
SOLUSI:
   a) Cek ukuran file < 100MB
   b) Format harus PDF (bukan Word, dll)
   c) Gunakan browser terbaru (Chrome/Firefox/Edge)

PROBLEM 5: Admin/Siswa tidak bisa login?
SOLUSI:
   a) Cek username/password (case-sensitive)
   b) Admin: admin/admin (semua huruf kecil)
   c) Siswa: NISN harus 10 digit
   d) Refresh halaman sebelum retry
